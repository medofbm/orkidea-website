# AGENTS.md - Orkidea repo

Read CLAUDE.md first; it is the shared technical brief. Same rules apply to every agent.

- Plan before editing; keep changes small and scoped to the task.
- Never commit secrets, runtime configuration or customer exports.
- Do not deploy, run production migrations, push or merge without explicit owner approval.
- Show evidence for completion: build output, test results, browser check.
- Update docs (`docs/`, README) in the same change when behaviour or commands change.
- Hand-off notes for the owner go in the owner's notes system, not in this repo.
