# خطة مطابقة Vue مع ستاجينج — أوركيديا

التاريخ: 2026-11-21. الهدف: واجهة Vue تكون بنفس احترافية وجمال موقع ستاجينج (Razor)، وتغطي ميزاته، وتبقى أنظف وأسرع منه. بعدها يصير Vue هو الموقع الوحيد ونوقف Razor.

المصادر (قراءة كود، بدون تشغيل): تدقيق تصميم ستاجينج (`Orkideya/Views`, `wwwroot/css/site.css`, `admin.css`, `wwwroot/js`)، جرد واجهة Vue (`frontend/`)، ومقارنة الميزات بين الكنترولرات وواجهات `/api/v1`.

---

## 1. الخلاصة بسطرين
- ستاجينج أقوى في **الإحساس**: بنفسجي واحد منضبط، تدرجات، هيدر زجاجي، بطاقات تطفو عند المرور، أزرار تلمع، كاروسيل، تقييمات، نموذج تواصل، صفحة تأكيد متحركة.
- Vue أقوى في **الأساس**: كود أنظف، اختبارات، وصول (accessibility)، أمان السلة والدفع، الإدارة أكمل. الناقص: نصف الصفحات بشكل قديم، وميزات (تقييمات، تواصل، استرجاع كلمة المرور، حذف، رسم المبيعات).

### 2.4 الحركة
ستاجينج: `circleFloat`, `glowPulse` 3s, `float` 4s, `gradientShift` 4s, `fadeInUp` .4s, `ping`, `pulse` .6s, `heartbeat`, `confirmBounce`, `confirmRing`. Vue: ضغط الزر، ارتفاع البطاقة، skeleton فقط.
**المقترح:** ننقل الحركات نفسها كـkeyframes في `main.css` مع احترام تقليل الحركة، ونضيف ظهوراً تدريجياً خفيفاً عند التمرير (ستاجينج ما فيه). ولا ننقل أخطاءه: `* { transition: all .3s }` على كل العناصر وتلاشي الصفحة كلها عند كل تحميل (يثقّلوا الموقع).

## 3. القرارات المقترحة (تحتاج موافقة المالك)
1. **ألوان ستاجينج تصير هي الهوية الرسمية** (`#6a1b9a` / `#4a148c` / `#9c4dcc` / `#e0b0ff` / لافندر). يُحدَّث `docs/brand/BRAND.md`.
2. **لا Bootstrap ولا SweetAlert ولا Swiper ولا Font Awesome CDN في Vue:** نفس الشكل بـTailwind ومكوّنات خفيفة وأيقونات SVG. السبب: سرعة وأمان (Swiper محمّل من رابط غير مثبّت في ستاجينج).
3. **التقييمات:** شريط "ماذا يقول زبائننا" يظهر فقط عند وجود تقييمات معتمدة حقيقية، والرقم "5 ★" يُحسب منها.
4. **استرجاع كلمة المرور:** نحتاج قرار القناة (بريد/واتساب/المالك يعيد التعيين من الإدارة). مؤقتاً: إعادة التعيين من الإدارة.

## 5. ما لا ننقله من ستاجينج (عيوبه)
- `* { transition: all .3s }` وتلاشي الصفحة عند كل تحميل: بطء وارتجاف.
- Swiper من رابط غير مثبّت الإصدار، وFont Awesome وخط Cairo من CDN: نستعمل نسخاً محلية.
- كتل CSS مكررة في `site.css`.
- صفحة الدفع والخصوصية والخطأ غير مصممة (الخصوصية والخطأ بالإنجليزي).
- نماذج تعيد تحميل الصفحة كاملة.
- رقم "5 تقييم" ثابت.
